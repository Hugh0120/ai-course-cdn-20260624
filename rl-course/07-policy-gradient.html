7.2 本章定位与学习主线

7.2.1 本章解决什么问题

前面的 value-based 方法先学习 Q(s,a)，再用 arg maxaQ(s,a) 选择动作。本章改变建模对象：直接学习动作分布 πθ(a∣ s)。

核心问题是：

动作是从策略分布中采样的，奖励又由不可微的环境产生，如何计算策略参数对期望回报的梯度？

7.2.2 整章推理链

策略是动作条件分布 pi_theta(a|s)
  -> 策略决定轨迹分布 p_theta(tau)
  -> 目标 J(theta) 是轨迹回报的期望
  -> Log-derivative Trick 把“对分布求导”改写成 log-probability 梯度
  -> 轨迹分解后只剩 policy 项
  -> Reward-to-go G_t 把未来回报分配给当前动作
  -> Q_pi(s,a) 是固定 (s,a) 后 G_t 的条件均值
  -> REINFORCE 用采样到的 G_t 估计期望梯度
  -> Baseline 在不改变梯度期望的前提下降低方差
  -> 选择 V_pi(s) 作为 baseline 后自然得到 Advantage

7.2.3 本章与第 8 章的边界

本章只使用完整未来奖励构造 Monte Carlo 学习信号：

  • REINFORCE 使用 Gt。
  • REINFORCE with baseline 使用 Gt-bφ(st)。
  • Baseline 可以是可学习网络，但它的监督标签仍是完整 Gt。

第 8 章才引入 Critic（价值评估器）和 bootstrap（自举：用当前价值估计构造新的学习目标），再展开 Temporal Difference（TD，时序差分）、n-step return（n 步回报）和 Generalized Advantage Estimation（GAE，广义优势估计）。

7.3 策略表示：统一看待离散、连续与混合动作

7.3.1 策略是条件分布

随机策略不直接输出“唯一正确动作”，而是输出给定状态下的动作分布：

At∼πθ(·∣ St)

训练时需要保存采样动作的 logπθ(At∣ St)，因为后面的 Policy Gradient 会用它建立“动作发生的可能性”与“动作之后的回报”之间的联系。

7.3.2 离散动作：Categorical Policy

若动作是有限个互斥选项，例如 left / stay / right，网络先输出 logits：

z=fθ(s)

再用 softmax 得到 categorical distribution（类别分布）：

πθ(a=i∣ s) =exp(zi) / ∑kexp(zk)

策略从这个分布采样一个动作。概率之和自动为 1，因此提高一个动作的概率会相对压低其他动作。

7.3.3 连续动作：Diagonal Gaussian Policy

若动作是 d 维连续向量：

a=(a1,a2,…,ad)

常见做法是让网络为每一维输出均值和标准差：

μθ(s), σθ(s)>0

若各维在给定状态后条件独立，联合概率密度分解为：

πθ(a∣ s) =∏j=1d 𝒩 (aj;μθ,j(s),σθ,j(s))

两边取对数：

logπθ(a∣ s) =∑j=1d log𝒩 (aj;μθ,j(s),σθ,j(s))

符号逐项解释：

  • 𝒩：花体大写 N，表示 Normal Distribution（正态分布，也叫高斯分布）的概率密度函数。
  • aj：本次实际采样的第 j 维动作值。
  • μθ,j(s)：策略网络预测的第 j 维均值。
  • σθ,j(s)：策略网络预测的第 j 维标准差；实现中常输出 log_std 再取指数，以保证标准差为正。
  • 分号 ;：左边是“在哪个动作值处计算密度”，右边是高斯分布的参数。
  • ∏j 变成 ∑jlog：条件独立时联合密度等于各维密度的乘积，对数把乘积变成求和。

例如二维动作为“转向、油门”：

a=(0.2,0.7), μθ(s)=(0.1,0.6), σθ(s)=(0.2,0.1)

这次动作的 joint log density（联合对数密度）是：

logπθ(a∣ s) =log𝒩(0.2;0.1,0.2) +log𝒩(0.7;0.6,0.1)

连续变量取到某个精确数值的概率为 0，因此这里严格来说是 probability density（概率密度），不是离散动作的 probability mass（概率质量）。工程中通常都简称 log_prob。

7.3.4 离散加连续：Hybrid Action Policy

混合动作同时包含离散类型和连续参数：

At=(Kt,Ut)

例如：

游戏：K_t = 选择技能，U_t = [瞄准角度, 释放距离]
交易：K_t = {不操作, 买入, 卖出}，U_t = [价格, 数量]

若连续参数的语义由离散类型决定，应使用 conditional factorization（条件分解）：

πθ(k,u∣ s) =πθd(k∣ s) πθc(u∣ s,k)

所以联合 log probability 为：

logπθ(k,u∣ s) =logπθd(k∣ s) +logπθc(u∣ s,k)

一次采样的顺序是：

state s
  -> categorical head 采样离散类型 k
  -> 选中 k 对应的 continuous head
  -> 从该连续分布采样 u
  -> 环境执行联合动作 (k,u)

如果每个离散类型都有自己的连续参数分支，只有本次被选中的分支会通过 logπθc(u∣ s,k) 获得直接梯度。未选中分支没有对应的实际动作和回报，不应把它们的 log probability 都加进 loss。

7.3.5 有界连续动作

真实动作常有范围约束，例如方向盘角度必须在 [-1,1]。直接从无界 Gaussian 采样后用 clip 截断，会改变实际执行分布，使得记录的 log probability 与真实动作不一致。

常见处理是：

  1. 从 Gaussian 采样无界变量。
  2. 用 tanh 压缩到 [-1,1]。
  3. 缩放到环境的合法范围。
  4. 计算 log probability 时加入 change of variables（变量变换）带来的 Jacobian correction（雅可比校正）。

本章不推导该校正公式，但要记住原则：动作经过可微变换后，log probability 必须对应变换后的真实分布。

7.4 从策略到轨迹期望目标

7.4.1 轨迹与 Reward-to-go

一条完整轨迹写成：

τ=(S0,A0,R1,S1,A1,R2,…,ST)

从时刻 t 开始的 reward-to-go 为：

Gt =∑k=tT-1 γk-tRk+1

Gt 是随机变量，因为未来状态转移和未来动作都可能随机。

7.4.2 期望回报目标

对从初始状态开始的 episodic task，策略目标可写成：

J(θ) =𝔼τ∼ pθ(τ)[G0]

它表示：按当前策略反复采样轨迹，期望上希望获得更大的 G0。

7.4.3 梯度难点在轨迹分布

目标中的轨迹分布 pθ(τ) 随策略参数 θ 变化：策略改变动作概率，动作又改变后续状态与奖励。

不能把环境当作普通监督学习网络直接反传，原因包括：

  • 离散动作采样不可微。
  • 环境转移未必可微，也未必知道其内部函数。
  • 奖励可能延迟很多步才出现。

Policy Gradient 的关键不是穿过环境反传，而是对“产生轨迹的概率”求导。

7.5 从轨迹目标到 Policy Gradient

7.5.1 对采样分布求导

对任意可微概率分布，Log-derivative Trick（对数导数技巧，也叫 Score Function Trick）为：

∇θ pθ(x) =pθ(x) ∇θlog pθ(x)

将它用到轨迹期望：

∇θ J(θ) =∇θ ∫ pθ(τ)G0 dτ
=∫ ∇θ pθ(τ)G0 dτ
=∫ pθ(τ) ∇θlog pθ(τ) G0 dτ
=𝔼τ∼ pθ [∇θlog pθ(τ)G0]

这一步把“对随 θ 变化的轨迹分布求导”转成了“在当前分布下采样，再对采样轨迹的 log probability 求导”。

7.5.2 展开轨迹概率

轨迹概率分解为：

pθ(τ) =p(S0) ∏t=0T-1 πθ(At∣ St) P(St+1∣ St,At)

取对数后乘积变成求和。初始状态分布 p(S0) 和环境转移 P 默认不依赖策略参数，因此：

∇θlog pθ(τ) =∑t=0T-1 ∇θ logπθ(At∣ St)

代回目标梯度：

∇θ J(θ) =𝔼τ [ ∑t=0T-1 ∇θlogπθ(At∣ St) G0 ]

环境决定哪些轨迹和奖励会被采样，所以环境当然影响梯度样本；“环境项消失”只表示不需要对环境转移函数求导。

7.5.3 用 Reward-to-go 完成 Temporal Credit Assignment（时间归因）

上式让每个时间步的动作梯度都乘上整条轨迹回报 G0，但 At 无法影响时刻 t 之前已经发生的奖励。

从期望梯度中去掉这些过去奖励项，不会改变梯度期望，但可以减少噪声。对从 G0 定义的折扣目标，严格写法为：

∇θ J(θ) =𝔼τ [ ∑t=0T-1 γt ∇θlogπθ(At∣ St) Gt ]

外层 γt 来自 G0 中第 t 时刻奖励的折扣位置，而 Gt 内部从当前时刻重新以 γ0 开始计算。

很多教材和实现在以下情况不显式写外层 γt：

  • episodic 任务使用 γ=1。
  • 将时间权重吸收进采样分布或目标定义。
  • 工程上直接使用 Gt 作为样本权重。

面试时要能说清所采用的目标定义，不要在不同公式约定之间机械比较是否“少了一个 γt”。

7.5.4 对未来随机性取条件期望

即使当前 (St,At) 完全相同，不同的环境转移和后续动作也会产生不同 Gt。固定 St=s,At=a 后对这些未来随机性取平均，定义出：

Qπ(s,a) =𝔼π [Gt∣ St=s,At=a]

它不是突然换了一个学习信号，而是给“Gt 的条件均值”起名为 Action-value Function。

对任意一个时间步，根据 iterated expectation（迭代期望，也叫全期望公式）：

𝔼 [∇θlogπθ(At∣ St)Gt]
=𝔼St,At [ ∇θlogπθ(At∣ St) 𝔼[Gt∣ St,At] ]
=𝔼St,At [ ∇θlogπθ(At∣ St) Qπ(St,At) ]

已知 (St,At) 后，∇θlogπθ(At∣ St) 已是确定量，因此可以移出内层条件期望。保留与上一小节一致的时间权重，Policy Gradient 可写成：

∇θ J(θ) =𝔼τ∼ pθ [ ∑t=0T-1 γt ∇θlogπθ(At∣ St) Qπ(St,At) ]

这一推导给出两个层次：

层次 数学对象 含义
单条轨迹 Gt 本次从 (st,at) 之后实际观测到的随机回报。
总体期望 Qπ(s,a) 固定 (s,a) 后，所有可能 Gt 的条件平均。

Policy Gradient 的期望表达式中出现 Qπ 并不表示必须训练 Q network。下一节会用实际轨迹中的 Gt 估计这个期望梯度。

7.6 REINFORCE：用轨迹样本估计 Policy Gradient

7.6.1 从期望梯度到样本梯度

REINFORCE 不先学习 Qπ。它采样完整轨迹，用本次观测到的 Gt 作为 Qπ(st,at) 的 Monte Carlo 样本。

保留严格的折扣时间权重，一条轨迹给出的梯度估计为：

gMC(τ) =∑t=0T-1 γt ∇θ logπθ(at∣ st) Gt

使用梯度上升更新策略：

θ ← θ+απ gMC(τ)

若实现框架默认最小化 loss，则使用负号：

LREINFORCE =- ∑t=0T-1 γt logπθ(at∣ st) Gt

Gt 在 policy loss 中是一个样本权重。不需要对环境奖励或 Gt 反向传播；梯度只通过 logπθ 进入策略参数。

7.6.2 完整训练流程

initialize policy pi_theta
repeat:
    use current pi_theta to sample complete episodes
    for each episode:
        compute every reward-to-go G_t backward
        read the saved log pi_theta(a_t | s_t)
        accumulate -gamma^t * log pi_theta(a_t | s_t) * G_t
    average the loss over sampled episodes
    update theta with gradient descent

一次训练样本的数据流为：

s_t
  -> policy distribution pi_theta(.|s_t)
  -> sample a_t and save log_prob_t
  -> environment returns r_{t+1}, s_{t+1}
  -> after episode ends, compute G_t
  -> loss_t = -gamma^t * log_prob_t * G_t

7.6.3 同一个 Loss 如何适配不同动作空间

REINFORCE 的整体 loss 形式不变，变的是 logπθ(at∣ st) 的计算方式：

动作空间 logπθ(at∣ st)
离散 categorical 被采样类别的 log probability。
多维连续 Gaussian 各维 Gaussian log density 之和。
离散 + 连续混合 离散类型 log probability + 被选中连续分支的 log density。

对混合动作 (kt,ut)：

Lt =-gammatGt [ logπθd(kt∣ st) +logπθc(ut∣ st,kt) ]

同一个 Gt 评价的是整个联合动作，所以它同时为离散决策和已选连续参数提供学习信号。

7.6.4 算法性质

REINFORCE 属于：

  • Policy-based：直接更新动作分布。
  • On-policy：训练数据由当前正在更新的策略产生。
  • Monte Carlo：需要观测完整未来奖励才能得到 Gt。
  • Model-free：不需要已知环境的转移函数。
  • No bootstrap：不用当前价值估计去构造 Gt。

7.6.5 Monte Carlo 梯度估计器的方差

固定同一 (st,at)，后续环境随机性和后续动作采样仍可能产生差异很大的 Gt。

例如五次从同一 (s,a) 开始得到：

G_t = 2, 18, -4, 25, 9

样本均值会逐渐接近 Qπ(s,a)，但单次更新可能被偶然的 25 或 -4 强烈影响。这就是下一节引入 baseline 的直接动机。

7.7 Baseline：不改变期望梯度的降方差方法

7.7.1 从绝对回报到相对回报

原始 REINFORCE 用 Gt 作为动作的样本权重。但一个回报的绝对数值未必能反映动作相对该状态的平均水平是好还是坏。

例如某个极难状态的平均回报是 -100，某动作这次得到 -60。虽然 -60 仍为负，它其实比该状态的平均表现好 40。

因此将学习信号改为：

Gt-b(St)

baseline 把“绝对回报”变成“相对参考水平的超额回报”。

7.7.2 Action-independent Baseline 不引入梯度偏差

对固定状态 s，如果 baseline b(s) 不依赖当前动作，则：

𝔼A∼πθ(·∣ s) [∇θlogπθ(A∣ s)b(s)]
=b(s) ∑a πθ(a∣ s) ∇θlogπθ(a∣ s)
=b(s) ∑a ∇θπθ(a∣ s)
=b(s) ∇θ ∑aπθ(a∣ s)
=b(s)∇θ1=0

连续动作时将求和换成积分，结论不变。因此：

𝔼 [∇θlogπθ(At∣ St)(Gt-b(St))]

与不减 baseline 的梯度期望相同。

关键限制是：baseline 在给定 St 后不能再依赖当前 At。若随意减去 b(St,At)，上述归一化证明不再成立，可能改变期望梯度。

7.7.3 State Value 是自然的 Baseline

对某个状态，当前策略的平均动作价值为：

Vπ(s) =𝔼A∼πθ(·∣ s) [Qπ(s,A)]

它正好表示“在该状态下，按当前策略正常行动能得到多少回报”。因此 Vπ(s) 是判断一个已选动作是否高于当前策略平均水平的自然参考值。

真实 Vπ 通常不可知，可以训练 bφ(s) 拟合 Monte Carlo return：

LV(φ) =1 / 2 ∑t=0T-1 [(bφ(St)-Gt)2]

因为：

𝔼[Gt∣ St=s] =Vπ(s)

在足够数据和足够表达能力下，回归 Gt 的 baseline 会逼近 Vπ(s)。

7.7.4 REINFORCE with Baseline

Monte Carlo advantage estimate 定义为：

ÂtMC =Gt-bφ(St)

policy loss 改为：

Lpolicy =- ∑t=0T-1 γt logπθ(at∣ st) ÂtMC

baseline loss 为：

Lbaseline =1 / 2 ∑t=0T-1 (bφ(st)-Gt)2

两个优化目标的梯度边界必须清楚：

  • 更新 policy 时，ÂtMC 作为已计算的样本权重，不通过它更新 baseline。
  • 更新 baseline 时，用 Gt 做回归标签，不通过 Gt 或 policy 反传。

完整流程：

sample complete episodes with current pi_theta
compute G_t for every time step
baseline prediction = b_phi(s_t)
MC advantage estimate = G_t - stop_gradient(b_phi(s_t))
update theta with policy loss
update phi with regression loss (b_phi(s_t) - G_t)^2

stop_gradient 表示在计算 policy loss 时把 baseline 预测当作已知数值，不让 policy loss 的梯度流入 baseline 参数 φ。

7.7.5 Baseline 的能力边界

  • action-independent baseline 保证的是“不改变期望梯度”，不是“任意 baseline 都必然降方差”。
  • baseline 需要与 Gt 的状态依赖变化足够相关，否则降方差效果可能很弱。
  • baseline 预测很差时，甚至可能增加样本方差。
  • baseline 只做中心化，不消除环境随机性和未来动作采样带来的所有噪声。

7.8 Advantage：将动作价值写成“状态水平 + 相对增益”

7.8.1 理论分解

Advantage Function 定义为：

Aπ(s,a) =Qπ(s,a)-Vπ(s)

等价地：

Qπ(s,a) =Vπ(s)+Aπ(s,a)

这是一个数学分解：

  • Vπ(s) 描述状态本身的平均水平。
  • Aπ(s,a) 描述特定动作相对这个平均水平好多少。

在当前策略的动作分布下，advantage 的加权平均为 0：

𝔼A∼π(·∣ s) [Aπ(s,A)] =0

7.8.2 理论 Advantage 与 Monte Carlo 估计

理论量是：

Aπ(s,a) =Qπ(s,a)-Vπ(s)

但 REINFORCE with baseline 在一条轨迹中拿到的是：

ÂtMC =Gt-bφ(st)

它们不是同一个数学对象：

对象 性质 来源
Aπ(s,a) 理论条件期望 真实 Qπ-Vπ。
ÂtMC 带噪声的单样本估计 一次 Gt 减去估计 baseline。

若 bφ 很好地近似 Vπ，则在固定 (s,a) 下反复采样：

𝔼 [ÂtMC∣ St=s,At=a] ≈ Aπ(s,a)

7.8.3 与 Actor-Critic 的分界

REINFORCE with baseline 和 Actor-Critic 的 policy loss 都可能写成：

Lpolicy =-logπθ(at∣ st) Ât

分界不在 loss 外观，而在 Ât 的构造方式：

方法 学习信号 Bootstrap 更新时机
REINFORCE Gt 否 通常等完整 episode。
REINFORCE with baseline Gt-bφ(st) 否 通常等完整 episode。
Actor-Critic TD error、n-step 或 GAE 通常是 可以在较短 rollout 后更新。

有些资料会将任意“带可学习 value baseline 的策略梯度”宽泛地称为 Actor-Critic。为了让学习主线清晰，本课程使用以下边界：

  • 只用完整 Gt 训练 baseline：仍归入 REINFORCE with baseline。
  • 价值估计器开始使用 Bellman bootstrap、TD 或 n-step target：进入第 8 章 Actor-Critic。

7.9 端到端例子

7.9.1 离散动作：Softmax Policy 更新

某状态下两个动作的当前概率为：

动作 当前概率
left 0.4
right 0.6

本次采样到 left，且 Gt=10。

  • 无 baseline 时，最小化 -logπ(left∣ s)×10 会提高 left 的概率。
  • 若 baseline 为 7，则 ÂtMC=3，仍提高 left 的概率，但更新强度取决于它高出参考水平多少。
  • 若 baseline 为 12，则 ÂtMC=-2，说明它虽然获得正回报，却低于该状态的预期水平，因此会降低 left 的概率。

7.9.2 连续动作：Gaussian Policy 更新

假设单维动作是方向盘角度，策略输出：

μθ(s)=0.1, σθ(s)=0.2

本次采样 at=0.3，并得到正的 ÂtMC。最小化：

-log𝒩(0.3;0.1,0.2) ÂtMC

会提高在该状态下采样到 0.3 附近动作的密度。梯度可能同时调整均值和标准差，不是简单把均值直接改成 0.3。

7.9.3 混合动作：技能与释放参数

假设策略先采样：

k_t = 火球术
u_t = [角度 20°, 距离 8]

训练信号为：

-ÂtMC [ logπθd(火球术∣ st) +logπθc([20,8]∣ st,火球术) ]

若 ÂtMC>0：

  • 离散分支会提高相似状态下选择火球术的概率。
  • 火球术对应的连续分支会提高采样类似角度和距离的密度。
  • 其他未选中技能的连续参数分支不获得这次动作的直接梯度。

7.9.4 理论 Advantage 与单次估计

某状态有三个动作：

动作 π(a∣ s) Qπ(s,a)
left 0.5 12
stay 0.3 8
right 0.2 4

状态价值为：

Vπ(s) =0.5×12+0.3×8+0.2×4 =9.2

理论 advantage 为：

Aπ(s,left)=12-9.2=2.8
Aπ(s,stay)=8-9.2=-1.2
Aπ(s,right)=4-9.2=-5.2

若本次采样 left，实际 Gt=15，baseline 预测 bφ(s)=9，则：

ÂtMC =15-9=6

这个 6 不等于理论 Aπ(s,left)=2.8，而是单条轨迹给出的带噪声估计。

7.10 章末统一视图

7.10.1 数学对象的层次

符号 层次 是样本还是期望 用途
Gt 单条轨迹 样本 REINFORCE 直接使用的 Monte Carlo return。
Qπ(s,a) 固定状态动作 条件期望 表示特定动作的平均未来回报。
Vπ(s) 固定状态 条件期望 表示当前策略在该状态的平均水平。
Aπ(s,a) 固定状态动作 条件期望 表示动作相对状态平均水平的增益。
ÂtMC 单条轨迹 样本估计 实现中用于 policy loss 的带噪声优势估计。

7.10.2 从建模到更新的完整闭环

1. policy network 输出动作分布
2. 从分布采样动作并保存 log_prob
3. 环境生成奖励和下一状态
4. episode 结束后反向计算 G_t
5. 可选：baseline 从状态预测参考回报
6. 构造权重 G_t 或 G_t-b_phi(s_t)
7. 用 -log_prob * weight 更新 policy
8. 若有 baseline，用 (b_phi(s_t)-G_t)^2 单独更新它

7.11 本章面试高频问题

7.11.1 Policy Gradient 为什么使用 ∇logπ？

Log-derivative Trick 将 ∇ pθ(τ) 改写为 pθ(τ)∇log pθ(τ)，使梯度可以写成当前轨迹分布下的样本期望。展开轨迹 log probability 后，只剩各时刻的 ∇logπθ(At∣ St)。

7.11.2 Gt 和 Qπ(s,a) 是什么关系？

Gt 是一条具体轨迹上的随机回报；Qπ(s,a)=𝔼[Gt∣ St=s,At=a] 是固定 (s,a) 后对所有可能未来取平均。REINFORCE 用实际采样的 Gt 作为 Qπ(st,at) 的 Monte Carlo 样本。

7.11.3 Reward-to-go 在推导中的作用是什么？

它将当前动作无法影响的过去奖励从当前梯度权重中去掉，保留当前动作之后的奖励。这是基于因果关系的 credit assignment，可以在不改变梯度期望的前提下降低方差。

7.11.4 Baseline 为什么不改变期望梯度？

给定状态后，若 baseline 不依赖当前动作，则 𝔼A∼π[∇logπ(A∣ s)b(s)]=0。因此减去 baseline 只会改变样本梯度的中心和方差，不改变期望。

7.11.5 为什么常用 Vπ(s) 作为 Baseline？

Vπ(s) 是在状态 s 下按当前策略选择动作的平均未来回报，正好是判断已选动作相对当前策略平均水平好坏的参考点。它未知时，可用 bφ(s) 回归 Monte Carlo return Gt。

7.11.6 理论 Advantage 和 Gt-bφ(st) 是同一个东西吗？

不是。Aπ(s,a)=Qπ(s,a)-Vπ(s) 是理论条件期望；Gt-bφ(st) 是一条轨迹上的 Monte Carlo 估计。当 baseline 近似 Vπ 时，后者的条件期望会近似前者。

7.11.7 REINFORCE with Baseline 与 Actor-Critic 的边界是什么？

本课程按学习信号区分：如果 baseline 只回归完整 Gt，不 bootstrap，仍属于 REINFORCE with baseline；当价值估计器用 TD、n-step 或其他 bootstrap target 构造 advantage 时，进入 Actor-Critic。

  1. Trajectory-level 推导：先将期望写成积分，得到 ∇ J=∫∇ pθ(τ)G0dτ；使用 ∇ p=p∇log p 得到 𝔼[∇log pθ(τ)G0]。
