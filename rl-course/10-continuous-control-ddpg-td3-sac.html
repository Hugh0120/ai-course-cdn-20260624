10.2 本章目标

学完本章，你应该能回答四个连续问题：

  1. 连续动作为什么不能直接照搬 DQN（Deep Q-Network，深度 Q 网络）的 maxa Q(s,a)？
  2. DDPG 怎样让 Actor 学成一个可微的近似 arg max？
  3. TD3 的三个改进为什么都在防止 Actor 利用 Critic 的误差？
  4. SAC 怎样从最大熵目标得到 Soft Bellman Target 和 Actor Loss？

10.3 本章主线

连续动作不能枚举
  -> 训练 Actor 直接输出高 Q 动作
  -> DDPG：确定性 Actor + 单 Critic + Replay
  -> Actor 会追逐 Critic 的虚假尖峰
  -> TD3：双 Critic + 延迟更新 + Target 平滑
  -> 外加动作噪声仍然是人为探索机制
  -> SAC：随机 Actor + 最大熵目标 + 双 Critic

三种算法不是互不相关的公式集合。DDPG 给出最基本的连续 Off-policy Actor-Critic；TD3修复它的价值估计问题；SAC进一步把探索写进优化目标。

10.4 从离散 Argmax 到连续 Actor

10.4.1 DQN 卡在哪里

离散动作 DQN 可以逐个计算 Q 值：

a*(s)=arg maxa∈AQ(s,a)

若动作是机械臂的 7 维关节力矩，每一维都连续，动作组合不可枚举。每个环境步都重新对 a 做数值优化也昂贵且不稳定。

连续控制因此增加一个 Actor：

a=μθ(s)

Critic 仍然回答“动作有多好”，Actor 学习“怎样一次前向就给出高价值动作”。可以把 Actor 理解为被训练出来的、摊销后的 arg max 求解器。

10.4.2 Actor 和 Critic 的职责必须分开

模块 输入 输出 学习信号
Critic (s,a) Qw(s,a) Bellman Target y
Actor s 动作 μθ(s) 或分布 πθ(·∣ s) Critic 对当前动作的评价

Critic 不是最终决策器；Actor 也不能凭空知道动作好坏。两者相互依赖，因此 Critic 的估值误差会直接影响 Actor。

10.5 DDPG：最基本的连续 Off-policy 闭环

10.5.1 为什么要有四个网络

DDPG 包含在线 Actor μθ、在线 Critic Qw，以及它们的慢速副本 μbarθ、Qbar w。

  • 在线网络负责学习。
  • 目标网络只负责构造 Target。
  • Replay Buffer 复用历史 Transition，因此算法是 Off-policy（异策略）：采样数据的旧行为策略可以不同于正在更新的当前 Actor。

10.5.2 Critic：先学会评价数据动作

从 D 采样 (s,a,r,s',d)。下一状态先由目标 Actor 给动作，再由目标 Critic 估值：

y=r+γ(1-d)Qbar wl(s',μbarθ(s')r)

Critic Loss（Critic 损失）为：

LQ(w)=𝔼(s,a,r,s',d)∼D [(Qw(s,a)-sg(y))2]

sg 是 Stop Gradient（停止梯度）：更新在线 Critic 时，y 被当作固定标签，不沿 Target 网络反传。

这里输入 Critic 的 a 是 Replay Buffer 中真实执行过的动作，因为它对应真实观测到的 r,s'。

10.5.3 Actor：把 Critic 当作可微评分器

Actor 要最大化当前 Actor 动作的 Q 值：

Jμ(θ)=𝔼s∼D [Qwl(s,μθ(s)r)]

对参数 θ 使用链式法则：

∇θ Jμ =𝔼s∼D [ .∇a Qw(s,a)∣a=μθ(s) ∇θμθ(s) ]

这两个因子分别回答：

  • ∇aQw：动作往哪个方向移动会提高 Q？
  • ∇θμθ：参数怎样变化才能让动作向那个方向移动？

更新 Actor 时，Critic 参数 w 固定，但保留 Q 对动作输入 a 的梯度。此处不能使用 Replay Buffer 里的旧动作 a，因为旧动作不依赖当前 θ，无法把梯度传回当前 Actor。

10.5.4 一个一维 Actor 梯度例子

假设某状态下 Critic 学到：

Q(s,a)=5-(a-0.7)2

当前 Actor 输出 a=μθ(s)=0.2，且在这个样本上 ∂μθ(s)/∂θ=0.5。则：

.∂ Q / ∂ a∣a=0.2 =-2(0.2-0.7)=1
∂ Jμ / ∂θ =1×0.5=0.5

梯度上升会增大 θ，从而让动作从 0.2 朝最优点 0.7 移动。若当前动作在 0.7 右侧，∂ Q/∂ a 会变成负数，参数就向相反方向更新。

10.5.5 Critic Target 数值例子

设 r=1、γ=0.99、d=0，目标 Actor 给出 a'=0.4，目标 Critic 估计 Qbar w(s',a')=4：

y=1+0.99×4=4.96

若在线 Critic 当前输出 3.5，单样本平方误差是：

(3.5-4.96)2=2.1316

若 d=1，则 y=r=1，不能再加入下一状态价值。

10.5.6 探索噪声和目标网络解决不同问题

DDPG 的 Actor 是确定性的。收集数据时通常执行：

at=clipA (μθ(st)+ξt)

ξt 负责探索；目标网络负责降低 Bootstrap Target 的快速漂移。两者不能互相替代。

目标网络使用 Polyak Soft Update（Polyak 软更新）：

bar w←(1-τ)bar w+τ w
barθ←(1-τ)barθ+τθ

10.5.7 DDPG 一轮训练的完整流程

初始化在线 Actor/Critic 和对应 Target 网络
初始化 Replay Buffer

重复：
    用 a = Actor(s) + exploration noise 与环境交互
    存储 (s, a, r, s', done)
    从 Replay Buffer 随机采样 batch
    用 Target Actor 和 Target Critic 构造 y
    最小化 (Q(s,a)-y)^2 更新在线 Critic
    最大化 Q(s, Actor(s)) 更新在线 Actor
    对两个 Target 网络做 Polyak 软更新

10.5.8 DDPG 为什么容易失败

Actor 会主动寻找 Critic 预测最高的动作。只要 Critic 某个未充分覆盖的区域出现虚假高峰，Actor 就会向那里移动，随后 Target 也可能使用这些不可靠动作 Bootstrap，形成正反馈：

Critic 偶然高估
  -> Actor 追逐高估区域
  -> Target 使用这个动作
  -> 高估继续传播

这正是 TD3 的出发点。

10.6 TD3：围绕“Actor 会利用 Critic 误差”做三项修复

10.6.1 Clipped Double Q：Target 取两个 Critic 的较小值

TD3 学两个独立 Critic Qw1,Qw2。Target 为：

y=r+γ(1-d) mini∈{1,2}Qbar wi(s',a')

如果一个 Critic 偶然高估，另一个没有同步高估，取较小值可减少过估计进入 Bootstrap Target。代价是可能略偏保守，但对确定性 Actor 而言通常比追逐虚假峰值更安全。

10.6.2 Target Policy Smoothing：不要相信孤立尖峰

TD3 不直接令 a'=μbarθ(s')，而是：

ε∼clip (𝒩(0,σtarg2I),-c,c)
a'=clipA (μbarθ(s')+ε)

σtarg 是 Target Noise Standard Deviation（目标噪声标准差），c 是噪声截断幅度。Critic 被迫学习动作邻域的平均质量，而不是依赖一个极窄的高值点。

注意两类噪声：

噪声 出现位置 目的
ξt 当前状态与真实环境交互 收集更多样的数据
ε 下一状态构造训练 Target 平滑 Q Target，抑制尖峰

10.6.3 Delayed Policy Update：Critic 多走几步，Actor 再跟

若每次 Critic 刚更新一步就让 Actor 追随，Actor 会放大 Critic 的短期噪声。TD3 通常每更新 Critic 多次，才更新一次 Actor 和 Target 网络。

“Delayed” 指 Actor/Target 的更新频率低于 Critic，不是把环境 Reward 延迟处理。

10.6.4 三项改进怎样组成一个闭环

双 Critic取 min：减少高估进入 Target
Target 平滑：减少 Critic 形成尖锐高估
延迟 Actor：减少 Actor 追逐尚未稳定的 Critic

10.6.5 TD3 数值例子

设 r=1、γ=0.99、d=0。目标 Actor 输出 0.60，采到 Target Noise -0.05，因此 a'=0.55。两个目标 Critic 分别输出：

Qbar w1(s',0.55)=8, Qbar w2(s',0.55)=5.5

则：

y=1+0.99×min(8,5.5)=6.445

若沿用单 Critic 的 8，Target 会是 8.92。TD3 不证明 5.5 一定正确，只是避免把某一个网络的乐观误差直接交给 Actor。

10.6.6 TD3 一轮更新

每个训练 step：
    1. 采样 replay batch
    2. 用 Target Actor + clipped noise 得到 a'
    3. 用两个 Target Critic 的 min 构造 y
    4. 更新两个在线 Critic
    5. 每隔 policy_delay 个 step：
         更新 Actor，使 Q1(s, Actor(s)) 增大
         软更新 Actor 和两个 Critic 的 Target 网络

Actor 通常只通过 Qw1 更新；双 Critic 的核心用途是构造保守 Target。

10.7 SAC：把探索写进最大熵目标

10.7.1 为什么 TD3 之后还需要 SAC

TD3 的探索依赖外加噪声及其调度。SAC 改用随机 Actor，并把策略熵放进目标，让“保持随机性”本身成为优化的一部分。

Maximum-entropy Objective（最大熵目标）为：

J(π)=𝔼π [∑t=0∞γt (Rt+1+αH(π(·∣ St)))]

因为：

H(π(·∣ s)) =-𝔼a∼π[logπ(a∣ s)]

单个采样动作对应的 Soft Value 项是 Q(s,a)-αlogπ(a∣ s)。

10.7.2 SAC Critic：Soft Bellman Target

SAC 通常也使用两个 Critic。对下一状态重采样 a'∼πθ(·∣ s')：

y=r+γ(1-d) [ mini∈{1,2}Qbar wi(s',a') -αlogπθ(a'∣ s') ]

两个 Critic 分别最小化：

LQi(wi)=𝔼D [(Qwi(s,a)-sg(y))2]

Soft Target 同时计入下一动作的长期 Reward 价值和策略随机性价值。

10.7.3 Soft Target 数值例子

设 r=1、γ=0.99、d=0、双 Q 较小值为 5、logπ(a'∣ s')=-0.7、α=0.2：

5-0.2×(-0.7)=5.14
y=1+0.99×5.14=6.0886

这里 -αlogπ 为正，不是“每个低概率动作都应被奖励”。它是熵的 Monte Carlo 样本，只有放在当前策略的动作分布期望下才等价于熵。

10.7.4 SAC Actor：从 Soft-greedy 分布得到 Actor Loss

给定一个 Soft Q，理想策略不是只选唯一最大动作，而是：

π*(a∣ s) ∝exp(Q(s,a) / α)

当前 Actor 可通过最小化下面的 Kullback-Leibler Divergence（KL 散度）逼近它：

DKL ( πθ(·∣ s) ∣dle∥ exp(Q(s,·)/α) / Z(s) )

Z(s) 是 Partition Function（配分函数），只依赖状态。展开并去掉与 θ 无关的常数，得到常用 Actor Loss：

Lπ(θ)=𝔼s∼D,a∼πθ [ αlogπθ(a∣ s) -miniQwi(s,a) ]

最小化它同时做到：

  • 让 Q(s,a) 变大；
  • 让 𝔼[logπ] 变小，也就是让熵变大。

10.7.5 连续采样怎样把梯度传回 Actor

常见 SAC Actor 输出高斯分布的均值和标准差，再重参数化：

ε∼𝒩(0,I)
u=μθ(s)+σθ(s)⊙ε, a=tanh(u)

随机性被放进与 θ 无关的 ε，所以 a 是 θ 的可微函数。Actor 梯度既经过 logπθ(a∣ s)，也经过 Q(s,a) 对动作的梯度。

由于 tanh 改变了概率密度，计算 logπ(a∣ s) 时必须加入 Change-of-variables Correction（变量变换校正）。面试中知道这一工程边界即可，不必现场展开 Jacobian 公式。

10.7.6 温度 α 如何自动调节

α 大时更重视熵，策略更随机；α 小时更重视 Q，策略更确定。设 Htarget 为 Target Entropy（目标熵），可用样本 -logπ(a∣ s) 估计当前熵，并优化：

Lα =𝔼[ α(-logπθ(a∣ s)-Htarget) ]

采用梯度下降时：

  • 当前熵低于目标，括号期望为负，α 会增大；
  • 当前熵高于目标，括号期望为正，α 会减小。

实现中通常优化 logα 来保证 α>0。不同代码对 Target Entropy 的正负号约定不同，判断时应回到“熵不足就增大 α”这一语义。

10.7.7 SAC 一轮训练的完整流程

用随机 Actor 与环境交互并写入 Replay Buffer
重复若干梯度步：
    采样 replay batch
    从当前 Actor 在 s' 重参数化采样 a'
    用双 Target Critic 的 min 和 -alpha log pi 构造 y
    更新两个在线 Critic
    从当前 Actor 在 s 重参数化采样新动作 a
    最小化 alpha log pi(a|s) - min Q(s,a) 更新 Actor
    可选：更新温度 alpha
    软更新两个 Target Critic

SAC 不需要 Target Actor，因为 Soft Target 的下一动作直接从当前随机 Actor 采样；目标双 Critic仍用于稳定 Bootstrap。

10.8 DDPG、TD3、SAC 的统一比较

维度 DDPG TD3 SAC
Actor 确定性 确定性 随机
数据使用 Off-policy Replay Off-policy Replay Off-policy Replay
Critic 单 Q 双 Q 双 Q
探索 外加交互噪声 外加交互噪声 最大熵策略
Target Action Target Actor Target Actor + 平滑噪声 当前 Actor 采样
Actor 更新 每步可更新 延迟更新 通常每个训练步更新
主要问题 容易利用 Q 高估 仍需手工探索噪声 实现更复杂，熵与温度需正确处理

选型直觉：

  • 学习主线和面试推导：先掌握 DDPG。
  • 确定性连续控制基线：优先 TD3，而不是原始 DDPG。
  • 希望较稳健探索和高样本复用：通常先尝试 SAC。

10.9 离散与连续混合动作不能直接套标准公式

若动作由离散类型 Kt 和条件连续参数 Ut 构成，例如“等待 / 买入 / 卖出”加“价格与数量”，应写成：

πθ(k,u∣ s) =πθd(k∣ s) πθc(u∣ s,k)

θd 和 θc 分别是 Discrete-head / Continuous-head Parameters（离散 / 连续分支参数）。标准 DDPG/TD3 假设动作整体可微，不能把离散 arg max 当作普通连续输出反传。

常见路线：

  1. 使用 PPO 等 Score-function 方法，联合两部分 Log Probability。
  2. 使用 Hybrid SAC 变体；离散类型较少时对 k 枚举，对条件连续动作采样。
  3. 使用 Parameterized-action 方法，让 Critic 显式评价 Q(s,k,u)。

10.10 实操检查：训练不稳定时看什么

现象 优先检查
Q 值快速发散 Terminal Mask、Reward 尺度、Target 更新、学习率
Actor 动作迅速顶到边界 动作缩放、Critic 虚假梯度、探索噪声、SAC 的 tanh 校正
Return 高度波动 随机种子、评估时是否关闭 DDPG/TD3 探索噪声、Replay Warm-up
TD3 没比 DDPG 稳 是否真的使用双 Target Q 的 min、延迟 Actor、Target Noise
SAC 熵持续坍缩 α 更新符号、Target Entropy、Log Probability 计算

评估确定性性能时，DDPG/TD3 应去掉探索噪声；SAC 常用分布均值或确定性模式执行。训练 Return 与无噪声 Evaluation Return 应分开记录。

10.11 面试高频问题

10.11.1 为什么 DQN 不适合连续动作？

因为 DQN 的决策和 Target 都依赖对动作枚举取 max。连续高维动作不可枚举，而每步额外做数值 Argmax 成本高且不稳，因此用 Actor 直接输出动作。

10.11.2 DDPG 的 Actor 为什么不用 Replay 中保存的动作？

Actor 要优化当前 Qw(s,μθ(s))。历史动作不依赖当前参数 θ，无法通过链式法则把 Critic 对动作的梯度传回 Actor。

10.11.3 TD3 的三个改进共同解决什么？

都在限制确定性 Actor 利用 Critic 的估值误差：双 Q 降低高估传播，Target 平滑抑制尖峰，延迟更新让 Actor 少追逐尚未稳定的 Critic。

10.11.4 SAC Actor Loss 为什么是 αlogπ-Q？

实现要最小化 Loss。最小化 -Q 会选择高 Q 动作；最小化策略期望下的 αlogπ 等价于最大化熵。它也可由当前策略逼近 exp(Q/α) 的 KL 投影推导出来。

10.11.5 SAC 为什么既是随机策略又是 Off-policy？

随机指 Actor 输出分布；Off-policy 指训练可以复用 Replay Buffer 中旧策略的数据。两者描述不同维度，并不矛盾。

10.11.6 Target Policy Smoothing 和探索噪声有什么区别？

前者只在训练 Critic Target 时出现，用于平滑价值估计；后者在真实环境交互时出现，用于扩大数据覆盖。
